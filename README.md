# Kresus

Application de bureau de gestion simple des finances familiales, pour les usages français, inspirée de Microsoft Money. L’interface et la documentation sont en français ; le code est en anglais.

- [Spécification et état fonctionnel](SPECIFICATION.md) : fonctionnalités réalisées, règles métier et besoins restant à traiter.
- [Guide de développement](kresus/README.md) : installation, tests, stockage et organisation du code.
- [Captures de référence](references/) pour l’interface.
